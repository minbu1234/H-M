## 2. 自分のパソコンで表示を確認する方法

### ① ファイルをパソコンに保存する

1. GitHubでこのリポジトリのページを開きます。
2. 画面左上のブランチ名（`main` と表示されているボタン）を押して、ホームページのファイルが入っているブランチを選びます。
   - `main` ブランチに取り込む前は **`claude/modest-thompson-4knwxh`** を選んでください。
   - 取り込んだあとは `main` のままで大丈夫です。
3. 緑色の **「Code」** ボタン → **「Download ZIP」** をクリックします。
4. ダウンロードしたZIPファイルを右クリック → **「すべて展開」**（Macはダブルクリック）で展開します。

> ブラウザの自動翻訳がオンになっていると、GitHubの表示が変わります。「main」は **「主要」**、「Code」は **「コード」** と表示されます。ファイル名やフォルダ名も日本語で表示されることがありますが、本当の名前は変わっていません。

### ② ブラウザで開く

1. 展開したフォルダの中の **`index.html`** をダブルクリックします。
2. ChromeやEdgeなどのブラウザでトップページが開きます。メニューから他のページにも移動できます。

> インターネットにつながっていなくても表示できます。

### ③ スマホでの見え方を確認する（Chrome・Edge）

1. ページを開いた状態で、キーボードの **F12** を押します（Macは `Command + Option + I`）。
2. 開いた画面の左上にある **スマホとタブレットの形のアイコン** をクリックします。
3. 画面上部の機種名（「Dimensions」など）で **iPhone** などを選ぶと、スマホの幅で表示されます。
4. 元に戻すときは、もう一度 **F12** を押します。

## 3. 文章を直す方法

### 使うソフト

- **おすすめ：Visual Studio Code（無料）**
  「VS Code」で検索してインストールし、`.html` ファイルを右クリック →「プログラムから開く」→「Visual Studio Code」で開きます。
- **Windowsのメモ帳でも直せます。**
  保存するときに、文字コードが **「UTF-8」** になっていることを確認してください（文字化けを防ぐため）。

### 手順

1. 直したいページの `.html` ファイルを、上のソフトで開きます。
2. **`Ctrl + F`**（Macは `Command + F`）で、直したい文章や **`【要入力`** を検索します。
3. 文章を書き換えます。
   ```html
   変更前： <p>【要入力】</p>
   変更後： <p>（ここに、答えの文章を書きます）</p>
   ```
4. **上書き保存**（`Ctrl + S`）します。
5. ブラウザで **F5**（再読み込み）を押すと、変更が反映されます。

### 直すときの注意

- `<` と `>` で囲まれた部分（**タグ**）は消さないでください。直すのは、タグとタグの**間の文字**だけです。
- `<!-- ▼○○ -->` は**メモ**です。画面には表示されません。そのまま残しても、消しても大丈夫です。
- 社名の「&」は、HTMLの中では **`&amp;`** と書いています（`H&amp;M` → 画面では「H&M」）。
- 段落を増やすときは、`<p>文章</p>` を1行追加します。
- 改行したいところには `<br>` を入れます。

### 全ページ共通の部分（4ファイルすべて直す必要があります）

次の部分は4つの `.html` ファイルのそれぞれに書いてあります。直すときは **4ファイルとも** 同じように直してください。

| 部分 | ファイル内の目印 |
|---|---|
| ヘッダー（社名とメニュー） | `<!-- ===== ヘッダー` |
| フッター（社名・住所・メニュー） | `<!-- ===== フッター` |

VS Codeを使う場合は、**`Ctrl + Shift + H`**（全ファイルで置換）を使うと、4ファイルをまとめて書き換えられます。

## 4. 【要入力】の場所の一覧

現在、【要入力】の箇所はありません。文章を書き足すときに、一時的に「【要入力】」と書いておくと、あとで検索して見つけやすくなります。

対応している会計ソフト（MJS、弥生会計、マネーフォワード クラウド会計）は、`services.html` の「対応範囲」の表の下の注意書きに書いてあります。対応するソフトが変わったときは、ここを直してください。

トップページの **検索結果に表示される説明文** は、`index.html` の上のほうにある `<meta name="description" content="…">` の `content="…"` の中です。画面には表示されませんが、Googleなどの検索結果で社名の下に表示されます。

> このサイトには、お問い合わせ先（電話番号・メールアドレス・お問い合わせページ）を載せていません。

### 会社概要について

会社概要は、登記簿謄本（履歴事項全部証明書）のとおりに書いています。
- 郵便番号（〒158-0097）は謄本に書かれていないため、用賀の郵便番号を調べて書いています。
- 代表者の自宅住所、会社法人等番号、株式の数は載せていません。
- 事業内容の2行目以降は、謄本の「目的」のうち、仕訳代行と財務分析に関係するものだけを、謄本の文言のまま載せています。

### サービス紹介ページの文章について

サービス紹介ページの文章は、同業他社のサイトの構成を参考にして新しく書いたものです。他社の文章や画像は使っていません。
サービスの内容が変わったときは、「サービス内容」「対応範囲」「ご依頼の流れ」などを合わせて直してください。

## 5. 料金を直す方法

料金は `pricing.html` に書いてあります。仕訳代行と財務分析の表の金額を、そのまま書き換えてください。

金額のあとのかっこ内は、税込の金額（税別の金額 × 1.1）です。税別の金額を変えたときは、**税込の金額も一緒に直してください**。

```html
<td>10,000円<span class="tax-in">（税込11,000円）</span></td>
```

仕訳代行の月額料金は、**仕訳数の区分**（50仕訳まで・51〜100仕訳・101〜200仕訳…）の表になっています。区分を増やすときは、表の行（`<tr>`〜`</tr>`）をコピーして書き換えてください。

月額料金（50仕訳までの金額）や初期費用を変えたときは、**トップページ（index.html）の「料金の目安」** も同じ金額に直してください。

### 料金の決め方（参考にした同業他社の料金）

仕訳代行の料金は、同業他社のホームページの料金表を参考にして決めました（2026年10月時点で調べたもの）。参考にしたのは料金の体系と金額の水準だけで、他社の文章はそのまま使っていません。

| 項目 | 他社の例 | このサイトの料金（税別） |
|---|---|---|
| 料金の決め方 | 月の仕訳数で区分する会社が多い。50仕訳ごとの区分が多い | 50仕訳まで、そのあとは100仕訳ごと |
| 〜100仕訳（入力をまるごと任せる場合） | 約1万円（6,600円〜16,500円） | 10,000円 |
| 〜200仕訳 | 約2万円（8,800円〜33,000円） | 20,000円 |
| 〜300仕訳 | 約3万円（16,200円〜33,000円） | 30,000円 |
| 1仕訳あたり | 入力をまるごと任せる場合は100〜110円が中心 | 約100円 |
| 初期費用 | 0円か、記載なしが多い | 0円 |
| 月次試算表 | 月額料金に含む会社が多い | 月額料金に含む |
| 証憑の整理 | 100仕訳あたり約5,000円 | 100仕訳ごとに月5,000円 |

## 6. 画像を追加したいとき

今のサイトには画像を使っていません。写真やロゴを入れたいときは、次の手順で追加できます。

1. `index.html` などと同じ場所に **`images`** という名前のフォルダを作り、写真を入れます。
   - ファイル名は **半角の英数字** にしてください（例：`office.jpg`）。日本語のファイル名は避けます。
   - 写真は `.jpg`、ロゴやイラストは `.png` がおすすめです。
   - 1枚 **500KB以下** を目安にしてください（大きすぎると表示が遅くなります）。
2. 画像を表示したい場所に、次の1行を書き足します。
   ```html
   <img src="images/office.jpg" alt="オフィスの様子">
   ```
   - `alt="…"` は、画像が表示されないときや、目の不自由な方の読み上げで使われる**画像の説明**です。
   - 画像は、画面の幅に合わせて自動で縮みます。
3. 保存して、ブラウザで再読み込み（F5）します。

> 他のサイトの写真は使わないでください（著作権の問題があります）。自社で撮影した写真か、利用が許可された素材を使ってください。

## 7. 色を変える方法

`css/style.css` の最初のほうにある **「色・文字・幅の設定」** を書き換えると、サイト全体の色がまとめて変わります。
（今は、M&Hのホームページと同じ色です。）

```css
:root {
  --color-main: #1e3a5f;        /* メインの色（濃い紺） */
  --color-main-dark: #142a46;   /* メインの色の濃いめ */
  --color-main-light: #e8eef5;  /* メインの色の薄いめ */
  ...
}
```

- `#1e3a5f` のような記号は、色を表す番号（カラーコード）です。
- 「カラーコード 一覧」などで検索すると、好きな色の番号を調べられます。

## 8. 項目を増やす・消す方法

### 表の行（会社概要・料金・対応範囲）

`<tr>` から `</tr>` までが1行です。
- **消すとき**：まとめて削除します。
- **増やすとき**：1行分をコピーして貼り付け、中身を書き換えます。

```html
<tr>
  <th>項目名</th>
  <td>内容</td>
</tr>
```

### サービスのカード

`<div class="card">` から、対応する `</div>` までが1枚です。コピーして増やしたり、削除したりできます。
トップページのサービスのカードも、合わせて直してください。

### こんなお悩み

`<li>` から `</li>` までが1行です。チェックマークは自動で付きます。

### ご依頼の流れ

`<li>` から `</li>` までが1段階です。番号（1, 2, 3…）は自動で付きます。

## 10. 公開する方法

M&Hのホームページと同じく、**GitHub Pages** で公開できます（無料のサーバーのようなものです）。

> **ご注意**：このリポジトリ（H-M）は **非公開（private）** です。GitHub Pagesで公開するには、次のどちらかが必要です。
> - リポジトリを **公開（public）** にする（M&Hのリポジトリは公開になっています）
> - GitHubの **有料プラン（GitHub Pro など）** を使う
>
> リポジトリを公開にすると、ホームページのファイルや変更の履歴を、誰でも見られるようになります。

### 手順

1. ホームページのファイルを **`main` ブランチ** に取り込みます（プルリクエストをマージします）。
2. （公開にする場合）**「Settings」→「General」** の一番下にある **「Change repository visibility」** で、**「Public」** に変更します。
3. **「Settings」→「Pages」** を開きます。
4. **「Build and deployment」** の **「Source」** を **「Deploy from a branch」** にします。
5. **「Branch」** で **`main`** と **`/ (root)`** を選び、**「Save」** を押します。
6. 数分待つと、画面の上に公開中のURLが表示されます（例：`https://minbu1234.github.io/H-M/`）。

### 公開したあとに直すとき

`main` ブランチのファイルを直すと、**1〜5分ほどで公開中のサイトにも自動で反映**されます。

1. GitHubでこのリポジトリを開き、直したいファイル（例：`pricing.html`）を押します。
2. 右上の **鉛筆のマーク**（「Edit this file」）を押します。
3. 文章を書き換えます（直し方は「[3. 文章を直す方法](#3-文章を直す方法)」と同じです）。
4. 右上の緑の **「Commit changes...」** を押し、出てきた画面でもう一度 **「Commit changes」** を押します。
5. 数分待ってから、公開中のサイトを開いて再読み込み（F5）し、反映されたことを確認します。
   - 反映が確認できない場合は、`Ctrl + F5`（Macは `Command + Shift + R`）で強制的に再読み込みしてください。

### 反映の状況を確認する方法

リポジトリ上部の **「Actions」** タブを開くと、「pages build and deployment」という作業の一覧が表示されます。緑のチェックが付いていれば反映済み、黄色の丸は反映中、赤のバツは失敗です。

### 公開をやめたいとき

**「Settings」→「Pages」** の画面にある **「Unpublish site」**（翻訳では「サイトを非公開にする」）を押すと、サイトの公開を止められます。
